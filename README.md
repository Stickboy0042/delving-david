## Important Status

This branch contains the Windows VM data package generated by GameMaker: `Delving David.win`.

The current Mac build environment does not include GameMaker's Windows runner/installer payload, so it cannot produce a final runnable `.exe` or Windows installer from here. To make this directly playable on Windows, build the project from GameMaker with the Windows export module/runner available, or run the final Windows packaging step on a Windows machine with the proper GameMaker runtime installed.

## Distribution Notes

This repo is being used as a lightweight build-sharing repo. For a larger release workflow, the cleaner GitHub pattern is to keep source code in the main project repo and attach platform builds to versioned GitHub Releases instead of committing every binary build into Git history.
